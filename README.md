# Мал санау

Қақпадан өткен малды санайтын Android қосымшасы (Flutter).

Қазіргі нұсқа (0.1): галереядан бейне таңдап, қолмен санау (кірді/шықты/баланс),
7 күндік тарих. Автоматты санау келесі нұсқада; `lib/gate_counter.dart` ішінде
бағытты сызықпен санау логикасы дайын және тестіленген.

APK: GitHub → Actions → Build APK → соңғы іске қосу → Artifacts → mal-sanau-apk.
